# Weather Mission Control
Weather Mission Control is an advanced beginner web app built with HTML, CSS, and JavaScript.
## Features
- Search real cities using the Open-Meteo Geocoding API
- Fetch real 7-day weather forecasts using the Open-Meteo Forecast API
- Display current weather, daily forecast cards, and a Chart.js line chart
- Save favorite cities with localStorage
- Keep recent searches
- Compare two favorite cities
- Deploy as a static site with GitHub Pages
## Files
- `index.html` - page structure
- `style.css` - design and responsive layout
- `script.js` - API calls, chart, favorites, comparison, and localStorage
- `README.md` - project explanation
